# Brazil administrative classification review

Checked 19 September 2026. No employment observations added.

The downloaded original IBGE CNAE 2.2 notes (PDF page 429) group games for all platforms with operating systems and general applications in 6203-1/00. The current indexed official lookup retains those broad descriptors. Therefore an employment total for this code is not a games workforce count. Each descriptor is not a separate queryable subclass.

Pages 285-286 describe 3240-0/01 as manufacturing and exclude videogame apparatus to 2640-0/00. Its games wording must not be used to substitute for software development employment.

An indexed 2026 IBGE news report says CNAE 3.0 implementation is planned for 2027. Full article access returned403. This is a timetable lead, not proof of an implemented games category or retrospective data. Earlier strategic implementation targets are insufficient evidence.

Abragames reports three newly recognized CBO occupations: visual game artist, game designer, game narrative designer. Its linked March2026 MTE article redirects to restricted content. Original codes and effective dates remain unverified. Occupation data would cover selected roles, not all workers in games establishments, and newly introduced categories cannot establish a long comparable history by themselves.

Decision: deprioritize a simple CNAE-only national workforce extraction. Continue surveys, or require a validated developer-company roster plus administrative linkage methodology. Keep the CBO route as a distinct future measurement lead. Next bounded Brazil lead is the Fortaleza2024 regional census, separate from national data.
