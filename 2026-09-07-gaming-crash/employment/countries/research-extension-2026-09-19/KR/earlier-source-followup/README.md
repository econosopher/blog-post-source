# Korea: earlier source recovery

[KOCCA 2012 summary](https://m.kocca.kr/knowledge/publication/indu/__icsFiles/afieldfile/2012/10/10/w0uw0G1FcfBw.pdf), PDF p. 8, Table 4, reports **43,365 game production/distribution workers in 2009**, excluding the separate venue row. Its 2010 and 2011 values exactly match the later KOCCA table already cataloged. Source PDF, text and inspected table image are archived here.

[KOCCA's own release](https://www.newswire.co.kr/newsRead.php?no=771789) dated 30 October 2014 directly confirms **40,541 for 2013**. It states that the publication surveyed 226 production/distribution firms, but supplies no weighting, gross-up, contractor or longitudinal-frame explanation. This strengthens provenance; it does not resolve comparability or the cause of the fall from 2012.

2009 is added to proposed observations as an isolated historical marker, pending integration review. Accepted annual ledger and regional chart unchanged. Full original methods remain a gap. A specific next lead is National Archives upper volume **DM00054095**, the 2015 White Paper; only its catalog listing was recovered.
